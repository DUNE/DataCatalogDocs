Official DUNE data datasets  
===========================

`Data catalog documentation <https://dune.github.io/computing-basics/OfficialDatasets>`_ is maintained in the `computing basics tutorial <https://dune.github.io/computing-basics>`_.

This is often all you need.  The syntax for queries using an official dataset is:

"files from <dataset namespace>:<dataset name> limit <number>"
